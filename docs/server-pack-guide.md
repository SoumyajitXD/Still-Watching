# Server Pack Guide

Still Watching server packs must match the official CurseForge release for the selected pack version.

## Safe rule

Use the CurseForge release as the source of truth. Do not treat the GitHub source ZIP as a playable modpack or server pack.

## Dedicated server notes

- Match the exact Still Watching version between clients and server.
- Match Minecraft `1.20.1`, Forge, configs, and required files.
- Remove only clearly client-side visual, shader, UI, resource-pack, map, audio-only, or rendering entries from a dedicated server.
- When a mod's side is uncertain, keep it until tested on a dedicated server.
- Back up worlds before updates or file changes.

This guide is intentionally conservative. Guessing at server-side compatibility is how you manufacture crash logs.
