STILL WATCHING

Forge 1.20.1 horror survival built around fog, sound cues, stalking entities, and hostile exploration.

The fog is not empty. The silence is not safety.

Official playable release: install through CurseForge. The GitHub repository is for source files, documentation, issue reporting, and transparency — not a playable modpack ZIP.

Install
Use the CurseForge App, search for Still Watching, and install the latest release.		 Recommended
Allocate 5GB minimum; 6–8GB is better. Use headphones.

WHAT THIS PACK IS

Still Watching is a focused Minecraft horror-survival modpack. It keeps the familiar loop — mine, build, travel, loot, return — then pushes it through fog, darkness, hostile structures, audio pressure, and things that follow.

This is not a kitchen-sink profile with monsters pasted on top. It is built for tense exploration, bad decisions under worse lighting, and the slow realization that a safe base is only safe until something starts testing the door.

PACK PILLARS

Fog-first atmosphere
Visibility is part of the threat. Distance, weather, terrain, and darkness turn normal travel into a risk calculation.		 Sound-led tension
Footsteps, knocks, whispers, growls, echoes, and distant movement become warnings before they become problems.
Stalking horror
Threats follow, ambush, mimic, punish careless routes, and wait for the moment you start acting comfortable.		 Survival pressure
Gear helps, but it does not make you safe. Preparation, escape routes, awareness, and backups matter more.

THE SURVIVAL LOOP

  1. Prepare before nightfall. Panic is expensive.
  2. Explore forests, caves, roads, towns, ruins, structures, and cursed places.
  3. Listen before you move. Sound is often the first warning and the last mercy.
  4. React when something turns the route home into a mistake.
  5. Return with loot, damage, worse nerves, and fewer lies about being safe.

EXPECT THIS

  • Fog-heavy horror exploration.
  • Sound-based danger cues.
  • Stalking entities and hostile encounters.
  • Caves, forests, roads, towns, ruins, and risky loot routes.
  • Multiplayer paranoia when the noise was not decorative.

DO NOT EXPECT THIS

  • A peaceful building therapy pack.
  • A pure tech, factory, or automation experience.
  • A safe power fantasy where gear solves every problem.
  • A random mod soup with horror sprinkled on top.
  • A pack that stays stable after careless extra-mod experiments.

INSTALLATION

  1. Install the CurseForge App.
  2. Search for Still Watching.
  3. Confirm the project is by Soumyajit.
  4. Install or update to the latest release.
  5. Allocate at least 5GB RAM; 6–8GB is preferred.
  6. Launch once clean before adding extra mods, shaders, resource packs, or config edits.

Using another launcher? Use one that properly supports CurseForge modpacks and the correct Forge 1.20.1 setup.

MULTIPLAYER / SERVER NOTES

Multiplayer works when the server and every client match. If they do not match, fix that before blaming the fog.

  • Use the same Still Watching version on server and clients.
  • Match Minecraft 1.20.1 and the required Forge version.
  • Keep required configs and server files aligned.
  • Back up worlds before updates, migrations, or major experiments.
  • Do not put client-only visual, shader, UI, map, audio-only, or rendering mods on a dedicated server.
  • Test world generation and joining before inviting players.

A mismatched server pack is not mysterious horror. It is bad admin work wearing a cheap mask.

BEFORE REPORTING ISSUES

Reproduce the problem on a clean CurseForge install when possible. A good report saves time; a vague report creates another monster.

Include Pack version, launcher, Minecraft version, Forge version if visible, Java version if relevant, OS, singleplayer or multiplayer, server host/RAM if relevant, crash report or latest.log, reproduction steps, and any extras you added.
Avoid “It broke fix pls”, screenshots of generic launcher errors only, edited profiles with unknown extra mods, or server files assembled by guessing.
