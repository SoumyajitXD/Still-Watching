WHAT THIS PACK IS

Still Watching is a focused Minecraft horror-survival modpack. It keeps the familiar loop—mine, build, travel, loot, recover—then pushes it through fog, darkness, hostile structures, audio pressure, and things that follow.

V2.0.0 rebuilds the pack instead of stuffing more mods into the old foundation. The terrain is larger, dimensions are stranger, mapping is cleaner, and the performance stack finally has actual teeth.

V2.0.0 WORLD OVERHAUL

The old Biomes O' Plenty-centered setup has been replaced by a more focused terrain and dimension stack:

  • Terralith expands Overworld biomes and terrain.
  • Tectonic creates larger mountains, valleys, and landforms.
  • Incendium rebuilds Nether exploration.
  • Nullscape transforms the End into a larger, harsher void.
  • Dungeons and Taverns, Explorify, and Towns and Towers expand structures.
  • Lithostitched supports the updated world-generation stack.

A new world is strongly recommended. Existing worlds may develop terrain borders, changed biome transitions, and new structures only in unexplored chunks.

HORROR THAT DOES NOT WAIT POLITELY

The One Who Watches joins The Anomaly, The Man From The Fog, From The Fog, Cave Dweller Reimagined, The Knocker, The Midnight Lurker, The Mimicer, Siren Head, GoatMan, Apollyon, and Eyes in the Darkness.

The goal is not a random monster pile. Sound, visibility, terrain, structures, stalking behavior, and uncertainty are designed to pressure the normal survival loop from several directions at once.

UPDATING FROM V1.1.2

  1. Back up the old instance and every important world.
  2. Install V2.0.0 as a fresh CurseForge profile when possible.
  3. Do not copy the entire old configuration folder over the new release.
  4. Create a new world for the intended terrain and structure experience.
  5. Preserve the old JourneyMap folder separately if its data matters.
  6. Test disposable copies before opening irreplaceable worlds or servers.

EXPECT THIS

  • Fog-heavy horror exploration.
  • Sound-based danger cues.
  • Large terrain and dimension overhauls.
  • Stalking entities and hostile structures.
  • Optional shaders with serious performance costs.

DO NOT EXPECT THIS

  • A peaceful building therapy pack.
  • A pure factory or automation experience.
  • A safe power fantasy where gear solves everything.
  • Perfect old-world migration across replaced generators.
  • Stability after careless extra-mod experiments.

MULTIPLAYER AND SERVERS

  • Use the same Still Watching version on the server and every client.
  • Match Minecraft 1.20.1, Forge, required mods, worldgen files, and configs.
  • Back up worlds before updates or migrations.
  • Do not place client-only shader, map, menu, audio, or rendering files on a dedicated server without confirming support.
  • Test Overworld generation, structures, Nether, End, joining, voice chat, and respawn before inviting players.

A mismatched server pack is not mysterious horror. It is bad admin work wearing a cheap mask.

BEFORE REPORTING ISSUES

Reproduce the problem on a clean CurseForge install. Include the pack version, launcher, Minecraft and Forge versions, Java version when relevant, operating system, RAM, new or migrated world status, crash report or latest.log, reproduction steps, shader settings, and every extra mod or config edit.

“It broke fix pls” is not evidence. It is a noise the fog makes.
