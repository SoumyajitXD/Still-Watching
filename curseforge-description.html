What Still Watching is

Minecraft is still here. Comfort is not.

Still Watching keeps the familiar survival loop—mine, build, travel, loot, recover and prepare—then forces it through dense fog, hostile structures, layered sound, visual pressure and encounters designed to make routine travel feel unsafe.

V2.0.0 is a rebuild rather than a pile-on. The world-generation stack, dimensions, mapping, performance foundation and horror roster were reorganized around one goal: create pressure before a creature even reaches you.

Pressure before spectacle

Fog, darkness, footsteps, echoes, distant noises and sudden silence do useful work before anything attacks.

Exploration with consequences

Larger terrain, rebuilt dimensions and expanded structures give you more reasons to leave shelter—and more ways for the return trip to become the real problem.

Tools, not invincibility

Maps, backpacks, security equipment and firearms improve your odds. They do not turn the pack into a consequence-free power fantasy.

Horror, sound and visual pressure

You will often hear the problem first.

AmbientSounds 6, Sound Physics Remastered, Presence Footsteps, EnhancedVisuals and Cave Dweller Sound Overhaul make caves, forests, weather and enclosed spaces feel physically different. Fresh Animations, Entity Model Features, Entity Texture Features and Tissou’s Zombie Pack strengthen the visual identity without replacing Minecraft with an unrelated game.

Headphones are strongly recommended. Directional sound is part of the warning system, not background decoration.

The things outside

The threat roster punishes different habits: careless cave exploration, predictable routes, late-night travel, isolated bases, ignored noises and the belief that locked doors settle the matter.

Shaders are included but optional. Lower or disable them first if performance drops.

Exploration, terrain and dimensions

A larger world with fewer safe assumptions.

V2.0.0 replaces the previous Biomes O’ Plenty-centered foundation with a more focused generation stack:

  • Terralith + Tectonic: expanded Overworld biomes with larger mountains, valleys and coastlines.
  • Incendium: expanded Nether terrain and exploration.
  • Nullscape: a larger, harsher End built around dramatic void landscapes.
  • Dungeons and Taverns + Explorify + Towns and Towers: the main structure layer, giving travel more destinations and more places for things to go wrong.

For the intended V2.0.0 experience, create a new world. Migrated worlds can show hard terrain borders, changed biome transitions, removed-mod remnants and new structures only in unexplored chunks.

Navigation, survival and progression

Tools help. They do not make you untouchable.

  • Xaero’s Minimap + Xaero’s World Map replace JourneyMap for navigation. Old JourneyMap waypoints and explored map tiles do not transfer automatically.
  • Timeless and Classics Zero Guns adds modern firearms for dangerous encounters.
  • TACZ: Durability adds maintenance and wear so firepower is not permanently consequence-free.
  • Traveler’s Backpack, Corpse and Security Craft make long trips, death recovery and base defence less tedious without removing danger.
  • FTB Teams, FTB Quests and Simple Voice Chat support group play, quest structure and communication.

Performance foundation

Better foundations, not magical FPS marketing.

Embeddium, Chloride, ImmediatelyFast, FerriteCore, ModernFix and FPS Reducer form the main rendering, memory and performance foundation. Oculus provides shader support for the included shader options.

Actual performance still depends on hardware, shader choice, render distance, simulation distance, entities and active terrain generation. Maximum settings plus a heavy shader can still turn expensive hardware into a haunted slideshow. Physics remains annoyingly employed.

Recommended setup

Start sane. Increase settings later.

RAM: 5 GB minimum; 6–8 GB preferred. Do not allocate every available gigabyte and starve the operating system.

Java: Java 17 when the launcher or server setup asks.

Render distance: start around 8–10 chunks if performance is uncertain.

Simulation distance: start around 5–6 chunks if CPU load is high.

Shaders: optional. Reduce shader quality or disable shaders before diagnosing general pack performance.

Audio: headphones are recommended; make sure Minecraft is using the correct output device.

Updating from V1.1.2

Do not feed an irreplaceable world directly into a major overhaul.

  1. Back up the old profile and every important world.
  2. Install V2.0.0 as a fresh CurseForge profile whenever possible.
  3. Do not copy the complete V1.1.2 config/ folder into V2.0.0.
  4. Create a new world for the intended terrain, structures and dimensions.
  5. Keep old JourneyMap data separately if its waypoints or explored tiles matter.
  6. Test migrated worlds only from disposable copies before touching anything irreplaceable.

Install and first launch

Use the official release. Test clean before you customize.

  1. Install the CurseForge App and open Minecraft.
  2. Search for Still Watching by Soumyajit.
  3. Install the latest public release for Minecraft 1.20.1 / Forge.
  4. Allocate at least 5 GB RAM; 6–8 GB is preferred when your system has room.
  5. Launch once with no extra mods, third-party shader packs, stacked resource packs or copied old configs.
  6. Create a new test world and confirm world generation, audio, controls, maps and performance before trusting a main save to the profile.

Do not use the GitHub repository ZIP as a modpack installer. GitHub is the source-side home for documentation, screenshots, support and release tracking; playable releases belong on CurseForge.

Multiplayer and servers

Supported when everyone is actually running the same pack.

  • Use the same Still Watching release on the server and every client.
  • Match Minecraft 1.20.1, the pack-required Forge build, required mods, configs, datapacks and world-generation files.
  • Do not put client-only shader, rendering, menu, map, visual or audio-only files on a dedicated server unless the author explicitly supports server-side use.
  • Back up server worlds before updates, migrations or configuration changes.
  • Before inviting a group, test joining, respawning, voice chat, structures, Nether travel and End travel with a clean matching client.

A mismatched server pack is not supernatural horror. It is bad administration wearing a cheap mask.

Before reporting an issue

Reproduce it cleanly. Bring evidence.

Test the problem on a clean CurseForge installation when possible. Remove extra mods, additional shader packs, stacked resource packs and unofficial config edits first.

A useful report includes the Still Watching version, launcher, Minecraft and Forge versions, Java version when relevant, operating system, RAM allocation, singleplayer or multiplayer status, whether the world is new or migrated, clear reproduction steps, shader/settings details, the crash report and latest.log.

“It broke fix pls” is not evidence. It is a noise the fog makes.
