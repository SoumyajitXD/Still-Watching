A focused horror-survival experience

Minecraft is still here. Comfort is not.

Still Watching keeps the familiar survival loop—mine, build, travel, loot, recover and prepare—then forces it through dense fog, hostile structures, distorted soundscapes and stalking encounters. The result is recognizable Minecraft survival with fewer safe assumptions.

V2.0.0 is a rebuild rather than a pile-on. World generation, dimensions, mapping, atmosphere, exploration and performance were reorganized around one job: make ordinary movement feel risky before a creature even appears.

Pressure before spectacle

Fog, darkness, footsteps, distant noises and sudden silence create tension before direct contact.

Exploration with consequences

Larger terrain, rebuilt dimensions and expanded structures give you more reasons to leave shelter—and more ways for the return trip to go wrong.

Survival, not invincibility

Maps, backpacks, security tools and firearms reduce frustration. They do not convert the pack into a consequence-free power fantasy.

Horror and atmosphere

You will often hear the problem first.

AmbientSounds 6, Sound Physics Remastered, Presence Footsteps, EnhancedVisuals and Cave Dweller Sound Overhaul make caves, forests, buildings and weather feel physically different. Fresh Animations, Entity Model Features, Entity Texture Features and Tissou’s Zombie Pack reinforce the visual identity without replacing Minecraft with an unrelated game.

Headphones are strongly recommended. Directional sound is part of the warning system.

Exploration, terrain and dimensions

A larger world with fewer safe assumptions.

V2.0.0 replaces the previous Biomes O’ Plenty-centered foundation with a more focused world-generation stack:

  • Terralith and Tectonic reshape the Overworld with expanded biomes, larger mountains, valleys and coastlines.
  • Incendium expands Nether terrain and exploration.
  • Nullscape rebuilds the End around larger, harsher void landscapes.
  • Dungeons and Taverns, Explorify, and Towns and Towers form the main structure layer.

Create a new world for V2.0.0. Existing worlds may develop hard terrain borders, changed biome transitions, removed-mod remnants and new structures appearing only in unexplored chunks.

Navigation and survival

Tools help. They do not make you untouchable.

  • Xaero’s Minimap and Xaero’s World Map replace JourneyMap. Old JourneyMap waypoints and map tiles do not transfer automatically.
  • Timeless and Classics Zero Guns provides modern firearms for dangerous encounters.
  • TACZ: Durability adds maintenance and durability instead of permanent consequence-free firepower.
  • Corpse, Traveler’s Backpack, Security Craft and Simple Voice Chat reduce frustration and support multiplayer without removing risk.

Performance foundation

Better foundations, not magical FPS marketing.

Embeddium, ImmediatelyFast, FerriteCore, ModernFix, FPS Reducer, Oculus and Chloride form the main rendering, memory and performance layer. Results still depend on hardware, shaders, render distance, simulation distance, entities and active world generation.

Heavy shaders and maximum settings can still turn expensive hardware into a haunted slideshow. The pack improves the foundation; it does not repeal physics.

Recommended setup

Start sane. Increase settings later.

RAM: 5 GB minimum; 6–8 GB preferred. Do not starve the operating system by allocating every available gigabyte.

Java: Java 17 when the launcher or server asks.

Render distance: Start around 8–10 chunks if performance is uncertain.

Simulation distance: Start around 5–6 chunks if CPU load is high.

Shaders: Optional. Lower or disable them before blaming the entire pack for low FPS.

Audio: Use headphones and verify the correct output device.

Updating from V1.1.2

Do not feed an irreplaceable world directly into a major overhaul.

  1. Back up the old profile and every important world.
  2. Install V2.0.0 as a fresh CurseForge profile whenever possible.
  3. Do not copy the complete V1.1.2 configuration folder into V2.0.0.
  4. Create a new world for the intended terrain, structures and dimensions.
  5. Preserve old JourneyMap data separately if its waypoints or explored tiles matter.
  6. Test disposable copies before opening anything irreplaceable.
 

Multiplayer and servers

Supported when everyone is actually running the same pack.

  • Use the same Still Watching release on the server and every client.
  • Match Minecraft 1.20.1, the required Forge build, required mods, configs, datapacks and world-generation files.
  • Do not place client-only shader, visual, UI, menu, map, audio-only or rendering files on a dedicated server unless the author explicitly supports server-side use.
  • Back up the server world before updates, migrations or configuration changes.
  • Test joining, respawning, voice chat, structures, the Nether and the End before inviting everyone.

A mismatched server pack is not supernatural horror. It is bad administration wearing a cheap mask.

Before reporting an issue

Reproduce it cleanly. Bring evidence.

Test the problem on a clean CurseForge installation before reporting it. Remove extra mods, additional shader packs, stacked resource packs and unofficial configuration edits first.

Include the pack version, launcher, Minecraft and Forge versions, Java version when relevant, operating system, allocated RAM, singleplayer or multiplayer status, whether the world is new or migrated, clear reproduction steps, shader settings, the crash report and latest.log.

“It broke fix pls” is not evidence. It is a noise the fog makes.
