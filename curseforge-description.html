A focused horror-survival experience

Minecraft is still here. Comfort is not.

Still Watching keeps the survival loop recognizable: mine, build, explore, loot, recover and prepare. Then it puts that loop inside dense fog, hostile structures, distorted soundscapes and encounters that make ordinary travel feel irresponsible.

V2.0.0 is not the old pack with more creatures stapled to it. Terrain, dimensions, mapping, performance, exploration and atmosphere were rebuilt around a clearer identity. More mods would have been easy. Better pressure was the actual job.

The design

Built around pressure, not random mod count

ATMOSPHERIC HORROR

Fog, darkness, footsteps, distant noises and sudden silence create tension before a creature even appears.

DANGEROUS EXPLORATION

Larger terrain, transformed dimensions and expanded structures give you more reasons to leave shelter—and more reasons to regret it.

SURVIVAL FIRST

Gear helps, maps help and firearms help. None of them turn the world into a safe power fantasy.

V2.0.0 world overhaul

A larger world with fewer safe assumptions

The previous Biomes O’ Plenty-centered foundation has been replaced by a more focused terrain, dimension and structure stack.

Terralith Expands Overworld biomes and terrain without replacing Minecraft’s core identity.
Tectonic Creates larger mountains, valleys, coastlines and dramatic landforms.
Incendium Rebuilds Nether exploration with new terrain and dangerous destinations.
Nullscape Turns the End into a larger and harsher void instead of a brief final stop.
Structures Dungeons and Taverns, Explorify, and Towns and Towers expand settlements, ruins and exploration targets.

Create a new world for V2.0.0. Old worlds may show abrupt terrain borders, changed biome transitions and new structures only inside unexplored chunks.

Audio and atmosphere

You will often hear the problem first

AmbientSounds, Sound Physics Remastered, Presence Footsteps, EnhancedVisuals and Cave Dweller Sound Overhaul make caves, forests, buildings and weather feel physically different.

Fresh Animations, Entity Model Features, Entity Texture Features and Tissou’s Zombie Pack reinforce the visual identity without replacing Minecraft with an unrelated game.

Headphones are strongly recommended. Laptop speakers whispering into a ceiling fan are not an atmospheric setup.

Performance foundation

Better foundations, not magical FPS marketing

V2.0.0 adds a stronger performance and memory stack, but results still depend on hardware, shaders, render distance, active entities, world generation and every extra mod you bolt onto the profile.

Embeddium Main Forge rendering optimization foundation.
ImmediatelyFast Reduces overhead across several rendering and interface paths.
FerriteCore Reduces memory usage.
ModernFix Provides broad loading, memory, stability and performance improvements.
FPS Reducer Reduces unnecessary resource use while Minecraft is inactive.
Oculus and Chloride Support shader rendering and additional graphics configuration.

Running heavy shaders, high render distance and every visual option at maximum remains an excellent way to convert expensive hardware into a haunted slideshow.

Recommended setup

Start sane. Increase settings later.

RAM 5 GB minimum; 6–8 GB preferred.
Java Java 17 when your launcher asks.
Render distance Start around 8–10 chunks.
Simulation distance Start around 5–6 chunks.
Shaders Optional. Lower or disable them first when FPS drops.
Audio Use headphones and verify the correct output device before deciding that the atmosphere is broken.

Navigation and survival

Tools help. They do not make you untouchable.

  • Xaero’s Minimap and Xaero’s World Map replace JourneyMap with a cleaner mapping setup.
  • Old JourneyMap waypoints and map tiles do not automatically transfer.
  • Timeless and Classics Zero provides modern firearms for dangerous encounters.
  • TACZ: Durability adds maintenance and durability instead of granting permanent consequence-free firepower.
  • Corpse, Traveler’s Backpack, SecurityCraft, Simple Voice Chat and other survival utilities reduce frustration without removing risk.

Updating from V1.1.2

Do not feed an important world directly into a major overhaul

  1. Back up the old CurseForge profile and every important world.
  2. Install V2.0.0 as a fresh profile whenever possible.
  3. Do not copy the entire V1.1.2 configuration folder into V2.0.0.
  4. Create a new world for the intended terrain, structures and dimension generation.
  5. Preserve old JourneyMap data separately when it matters.
  6. Test disposable world copies before opening anything irreplaceable.

EXPECT THIS

  • Fog-heavy horror exploration.
  • Sound-based warning cues.
  • Large terrain and dimension overhauls.
  • Stalking entities and hostile structures.
  • Optional shaders with real performance costs.

DO NOT EXPECT THIS

  • A peaceful building therapy pack.
  • A kitchen-sink collection without direction.
  • A power fantasy where equipment solves everything.
  • Perfect migration across replaced world generators.
  • Guaranteed stability after random extra-mod experiments.

Multiplayer and servers

Supported when everyone is actually running the same pack

  • Use the same Still Watching release on the server and every client.
  • Match Minecraft 1.20.1, Forge, required mods, world-generation files and configs.
  • Keep client-only shader, visual, menu, map and rendering files off dedicated servers when required.
  • Back up the server world before updates or configuration changes.
  • Test joining, respawning, voice chat, structures, the Nether and the End before inviting everyone.

A mismatched server pack is not supernatural horror. It is bad administration wearing a cheap mask.

Before reporting an issue

Reproduce it cleanly and bring evidence

Test the issue on a clean CurseForge installation before reporting it. Remove extra mods, stacked resource packs, unofficial configuration edits and third-party shaders first.

Include the pack version, launcher, Minecraft and Forge versions, Java version when relevant, operating system, allocated RAM, singleplayer or multiplayer status, new or migrated world status, reproduction steps, shader settings, crash report and latest.log.

“It broke fix pls” is not evidence. It is a noise the fog makes.
