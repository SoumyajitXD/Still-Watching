# Security Policy

Still Watching is a Minecraft Java Edition horror-survival modpack. Most problems here are gameplay bugs, mod conflicts, broken installs, bad configs, or cursed launcher behavior — annoying, yes; security vulnerabilities, usually no.

Security reports are for risks that could harm players, servers, maintainers, or the project’s distribution chain. Do not turn every crash into a five-alarm exploit bonfire.

---

## Official Release Source

Install playable releases from the official CurseForge project:

- [Still Watching on CurseForge](https://www.curseforge.com/minecraft/modpacks/still-watching)
- [Still Watching files](https://www.curseforge.com/minecraft/modpacks/still-watching/files)

The GitHub repository is for source-side project files, documentation, validation, issue tracking, screenshots, release metadata, and licensing clarity.

The GitHub ZIP is **not** a playable modpack installer. If someone tells players to install Still Watching from a random ZIP, mirror, reupload, shortened link, or mystery launcher, treat that as suspicious until proven otherwise.

---

## Supported Versions

| Version | Support status |
| --- | --- |
| Latest CurseForge release | Primary support |
| Older CurseForge releases | Best-effort support |
| GitHub ZIP / source download | Not a supported playable install |
| Third-party reuploads, mirrors, or modified packs | Not supported |

Older releases may still get help when the report is clear and useful, but the latest CurseForge release is the baseline. Bugs already fixed in newer releases will not be chased through the woods forever.

---

## What Counts as a Security Concern?

Open a GitHub issue if you find or suspect:

- fake Still Watching downloads, mirrors, or installers;
- tampered files pretending to be official releases;
- malicious links in issues, comments, documentation, release notes, or project pages;
- accidental exposure of secrets, tokens, private server addresses, credentials, or private files;
- project files that could mislead users into unsafe installation behavior;
- supply-chain concerns around release references, downloads, attribution, or dependency metadata.

Bring evidence: links, screenshots if useful, filenames, where you found the problem, and what made it suspicious.

---

## What Is Usually Not a Security Concern?

These belong in normal bug/support channels, not security reports:

- crashes;
- broken installs;
- missing dependencies;
- mod conflicts;
- poor FPS, lag, or memory pressure;
- server startup failures;
- broken configs;
- horror mobs being unfair, loud, invisible, rude, or emotionally unemployed;
- issues caused by extra mods, shaders, resource packs, cracked launchers, or modified pack files.

If the issue only affects gameplay or stability, file it as a normal bug with logs and reproduction steps.

---

## Reporting Security Issues

For now, use GitHub Issues for reports that are safe to discuss publicly:

- [Open an issue](https://github.com/SoumyajitXD/Still-Watching/issues)

Do **not** publicly post secrets, tokens, private server IPs, passwords, private logs, or anything that would make the situation worse by being indexed forever.

If a report contains sensitive details, redact the sensitive parts before posting. A Discord server may be added later, but it is not an official support or security-reporting route yet.

---

## Before Posting Logs

Logs and crash reports can contain personal or server-specific details. Check before sharing:

- usernames;
- local file paths;
- server addresses;
- tokens or session-like strings;
- private modpack/server information;
- IP addresses or hostnames you do not want public.

Post the smallest useful log section that still proves the issue. Evidence is good. Doxxing yourself by accident is not character development.

---

## Maintainer Response

Reports will be reviewed as time allows. Valid security concerns may result in documentation fixes, warning notices, issue cleanup, link removal, release-note corrections, or other repository changes.

Reports without evidence may be closed. Panic is not a reproduction step.
