# Security Policy

Still Watching's playable releases are distributed through official CurseForge files. Random reuploads are not convenience; they are how players invite malware to dinner.

Current documented baseline:

| Item | Value |
| --- | --- |
| Release | Still Watching V1.1.0 |
| Minecraft | `1.20.1` |
| Loader | Forge |
| Java | Java 17 where required |
| Official install source | CurseForge |
| CurseForge Project ID | `1420406` |

## Supported Release Source

Use the official CurseForge project page and files page:

- [Still Watching on CurseForge](https://www.curseforge.com/minecraft/modpacks/still-watching)
- [Still Watching Files](https://www.curseforge.com/minecraft/modpacks/still-watching/files)

This repository does **not** provide executable installers outside CurseForge releases. The GitHub ZIP is repository source content, not a playable modpack installer.

## Report Security Concerns

Open a GitHub issue when you find:

- suspicious Still Watching downloads or reuploads;
- fake installer links;
- tampered files pretending to be official releases;
- malicious links in docs, issues, comments, or release references;
- accidental exposure of secrets, tokens, private server data, or unsafe files.

Include evidence: link, screenshot if useful, where you found it, and what looked wrong.

## Do Not Post Secrets

Logs may contain usernames, local paths, server addresses, tokens, or private system details. Review them before posting publicly.

Security reports need facts, not panic smoke. Bring proof; leave the cursed download alone.
