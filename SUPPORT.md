# Support

## Player install/help
Use CurseForge and the installation guide first:
- https://www.curseforge.com/minecraft/modpacks/still-watching
- ./installation-guide.md

## What GitHub Issues are for
- Reproducible crashes/bugs
- Server/multiplayer setup failures with logs
- Documentation errors
- Compatibility reports with clear steps

General "how do I mod Minecraft" support should stay out of Issues unless tied to reproducible pack defects.
