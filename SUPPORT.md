| Item | Value |

| CurseForge Project ID | `1420406` |

## Player Install Help

Use CurseForge and the installation guide first:

- [Still Watching on CurseForge](https://www.curseforge.com/minecraft/modpacks/still-watching)
- [Installation guide](./installation-guide.md)

The GitHub ZIP is not a playable installer. Do not use it as one.

## What GitHub Issues Are For

Open an issue for:

- reproducible crashes or bugs;
- server or multiplayer setup failures with logs;
- documentation errors;
- compatibility reports with clear steps and clean-install testing;
- suspicious links, broken release references, or attribution problems.

## What GitHub Issues Are Not For

- General "how do I mod Minecraft" support.
- Broken installs built from the GitHub ZIP.
- Extra-mod support unless the issue also happens on a clean CurseForge profile.
- Crash screenshots without logs.
- Vague "fix pls" reports. That is not a bug report; that is a haunted fortune cookie.

## Before Asking for Help

1. Install from CurseForge.
2. Launch once with no extra mods, shaders, or resource packs.
3. Confirm Minecraft `1.20.1`, Forge, and Java 17 if relevant.
4. Allocate `5 GB` minimum RAM; `6–8 GB` preferred.
5. Check `logs/latest.log` and any crash report.
6. Include reproduction steps.

Useful support starts with evidence. The crash log is the crime scene. Bring it.
