## Repository Notes

### Landing-page and community-surface polish

- Improved the GitHub landing page structure for faster player, server-admin, and contributor orientation.
- Added a clearer star/share section so people know how to support discovery without writing code.
- Linked the changelog, support policy, contribution guide, security policy, issue templates, and pull request template from the repository map.
- Kept CurseForge as the official playable install source.
- Kept the warning that the GitHub ZIP is not a playable modpack installer and is not a server pack.

- CI validates repository hygiene, metadata, internal links, workflow safety, Markdown, release-facing HTML, and mod-list consistency.
- Issue templates guide bug, crash, install, performance, server, and feature reports into useful evidence.
- Support and security docs clarify official-source safety, log privacy, and redistribution risks.
