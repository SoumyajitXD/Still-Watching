## V2.0.0 Is a Major Rebuild

Still Watching V2.0.0 is not V1.1.2 with a larger version number stapled to it. The pack has been rebuilt around four priorities:

- **more deliberate horror encounters;**
- **larger and more varied exploration;**
- **stronger performance and memory foundations;**
- **a cleaner mod selection with obsolete systems removed.**

The world-generation stack now combines **Terralith**, **Tectonic**, **Nullscape**, **Incendium**, **Lithostitched**, **Dungeons and Taverns**, **Explorify**, and **Towns and Towers**. The pack also adds **The One Who Watches**, replaces JourneyMap with **Xaero's Minimap** and **Xaero's World Map**, and introduces **ImmediatelyFast**, **FerriteCore**, **ModernFix**, and **FPS Reducer**.

A new world is strongly recommended. Mixing V1.1.2 terrain with V2.0.0 generation is how chunk borders become modern art.

## Why Play It

**Still Watching** is a Minecraft Java Edition horror-survival modpack by **Soumyajit** for **Minecraft `1.20.1`** on **Forge**.

It keeps the familiar survival loop—mine, build, loot, travel, recover—then poisons it with fog, darkness, hostile structures, layered sound, stalking entities, and enough uncertainty to make every quiet cave feel staged.

This is not a kitchen-sink pack wearing a cheap horror mask. It is built to make survival feel watched. 🕯️

## Updating from V1.1.2

1. Back up the entire instance and every world you care about.
2. Prefer installing V2.0.0 as a fresh CurseForge profile.
3. Do not overwrite V2.0.0 with the entire V1.1.2 `config/` folder.
4. Create a new world for the intended V2.0.0 terrain and structure experience.
5. Reconfigure personal keybinds, shaders, voice chat, and graphics settings as needed.
6. JourneyMap data does not automatically migrate to Xaero's mapping system.
7. Test a disposable copy before opening an irreplaceable old world.

Existing worlds may show terrain borders, changed biome transitions, missing removed-mod content, and new structures only in unexplored chunks.

## Install Fast

1. Install the [CurseForge App](https://www.curseforge.com/download/app).
2. Open the [Still Watching CurseForge page](https://www.curseforge.com/minecraft/modpacks/still-watching).
3. Confirm the project is by **Soumyajit**.
4. Install **Still Watching V2.0.0** or the newest compatible release.
5. Allocate **`5 GB` minimum RAM**; use **`6–8 GB`** if your system allows it.
6. Use **Java `17`** if the launcher asks.
7. Launch once clean before adding extra mods, shaders, resource packs, or config edits.
8. Create a new test world before trusting your main save to the update.

Need manual import notes, backup steps, multiplayer setup, RAM conversion, or troubleshooting? Read the [Installation Guide](./installation-guide.md).

## Multiplayer and Servers

Multiplayer is supported when the server and every client match.

- Use the same Still Watching version on the server and all clients.
- Use Minecraft `1.20.1` and the required Forge build.
- Keep configs, datapacks, worldgen dependencies, and server files aligned.
- Back up worlds before updates, migrations, config edits, or mod removals.
- Test startup, world generation, joining, voice chat, structures, dimensions, and respawning before inviting players.
- Do not upload client-only shaders, maps, menus, audio, or rendering mods to a dedicated server without confirming server support.

For conservative server-pack rules, read [`docs/server-pack-guide.md`](./docs/server-pack-guide.md).

## Reporting Issues

Before opening an issue, reproduce the problem on a clean CurseForge installation when possible.

Include:

- Pack version, for example `Still Watching V2.0.0`.
- Launcher, Minecraft, Forge, Java, and operating-system details.
- Singleplayer or multiplayer status.
- Server host and RAM when relevant.
- Crash report or `latest.log`.
- Exact reproduction steps.
- Whether the world was created on V2.0.0 or migrated from an older release.
- Any extra mods, shaders, resource packs, or config edits.

Logs matter. Vibes are not diagnostics.
